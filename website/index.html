The idea

A shared view.
A coordinated decision.

A vehicle can only react to what it knows. NexusPilot combines local camera detections with information from nearby vehicles, then uses that shared view to plan movement and negotiate intersection conflicts.

The same modular stack spans simulated roads and a physical 4WD platform, making perception, planning and cooperation easier to study together.

Lightweight vision

YOLO11n detection and IoU tracking identify vehicles, pedestrians and cyclists. The detector supports PyTorch, ONNX Runtime and OpenVINO backends.

perception/ ↗

Planning beyond local minima

Rotational fields complement attractive and repulsive forces. Stuck detection, recovery logic and steering smoothing help the planner handle difficult obstacle layouts.

planning/ ↗

Decisions between vehicles

Nearby vehicles exchange observations and intent. Distance-aware coordination and time-to-intersection estimates guide yielding, slowing and proceeding.

cooperation/ ↗

Two deployment environments

CARLA provides repeatable scenarios. Raspberry Pi 5 connects the stack to camera input, ultrasonic sensing and motor control on a physical 4WD car.

git clone https://github.com/JewelRoam/NexusPilot.git
cd NexusPilot
python -m venv .carla_env
source .carla_env/bin/activate
pip install -r requirements.txt

python simulation/multi_vehicle_demo.py

Linux/macOS shell. Start the CARLA 0.9.13 server first; Python 3.8 is recommended by the repository for CARLA compatibility. Windows activation steps are in the setup guide.
